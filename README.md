# Suhan Alam Rana

**AI & automation consultant.** I help businesses cut manual work with n8n workflow automation, AI chatbots and custom web systems.

The work usually starts by mapping how a business actually runs — where the repeated copying, chasing and re-typing happens — and then removing those steps. Automation first, custom development where a system needs to be built rather than connected.

12+ years · 300+ projects · Working with clients worldwide.

---

### What I work on

- **Process automation** — n8n workflows that move data between the tools a business already pays for, with the error handling and retries that decide whether an automation survives its first bad week.
- **AI chatbots** — support and sales bots grounded in a business's own content, with a human handoff path for everything the bot shouldn't answer.
- **AI & API integration** — OpenAI and Claude wired into existing systems; the model stays swappable.
- **Custom web development** — WordPress, WooCommerce, Laravel and React, as the foundation the automation runs on.

### How I tend to work

- Map the process before automating it. Automating a broken process just makes it fail faster.
- Automate the plumbing, not the judgment. Refunds, complaints and hiring decisions stay with a person.
- Build the stop conditions before the send conditions.
- Fixed-price proposals for almost everything, so the estimate is my problem rather than the client's.
